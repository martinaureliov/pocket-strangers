# Music credits

The music in this folder (and the two stings `sfx_sting_reveal.ogg` and `sfx_sting_success.ogg` in `assets/audio/sfx/`) was generated with Google's Lyria models via the Gemini API, using `tools/audio/generate_music.py`. The audio carries a SynthID watermark. The prompts deliberately describe musical style only (instruments, tempo, key, mood); they name no game, composer or artist.

Post-processing (trim, loop crossfade, loudness normalisation, Ogg Vorbis encode) is done by the same script. Raw model output is kept outside the repository in `build/audio_raw/`.
